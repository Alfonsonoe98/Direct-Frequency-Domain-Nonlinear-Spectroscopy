\section{Numerical Validation}
\label{sec:validation}

\subsection{External Finite-Pulse Benchmark}
\label{sec:validation_smallwood}

We first validate the finite-pulse implementation against an
independent analytical result.
Smallwood \textit{et al.} derived perturbative third-order solutions of
the optical Bloch equations for finite-duration Gaussian pulses,
providing an analytical benchmark for two-dimensional coherent
spectroscopy beyond the impulsive limit
\cite{Smallwood2017FinitePulse}.
The same model was subsequently used by Rose and Krich to validate the
UF$^2$ finite-pulse algorithm
\cite{RoseKrich2021UF2}.

We reproduce this three-level rephasing two-dimensional photon-echo
benchmark using Model B of Sec.~\ref{sec:theory}, since the analytical
treatment retains finite pulse duration while employing the
rotating-wave approximation.
The spectral coordinates are identified as
$\omega_1=\omega_\tau$ and $\omega_3=\omega_t$.
Because the two calculations employ different Fourier and response
normalizations, the analytical Smallwood result is converted to the
PULSUS convention through the fixed relation
%
\begin{equation}
S_{\mathrm{PULSUS}}
=
-i\,2\pi\,S_{\mathrm{Smallwood}} .
\label{eq:smallwood_conversion}
\end{equation}
%
This factor follows entirely from the respective transform conventions
and is not fitted to the numerical result.

For the primary comparison, the waiting time is chosen as
$T=2\pi\sigma$, for which the pulses are sufficiently separated for
the factorization used in the PULSUS finite-pulse formulation.
Using the relative Frobenius discrepancy
%
\begin{equation}
\epsilon_{\mathrm{val}}
=
\frac{
\left\|
S_{\mathrm{num}}-S_{\mathrm{ana}}
\right\|_F
}{
\left\|
S_{\mathrm{ana}}
\right\|_F
},
\label{eq:validation_error}
\end{equation}
%
PULSUS agrees with the analytical spectrum to
$\epsilon_{\mathrm{val}}=7.33\times10^{-6}$,
corresponding to a relative discrepancy of $0.000733\%$.
For the same benchmark, the discretized UF$^2$ result used here differs
from the analytical spectrum by $0.343\%$.
The comparison is intended as an implementation and convention check,
rather than as a general accuracy ranking between the two numerical
methods.

Increasing the pulse separation to $T=8\sigma$ reduces the PULSUS
discrepancy to $1.70\times10^{-8}$.
The decrease is consistent with the remaining error at finite
separation arising from the separated-pulse time-ordering
approximation rather than from the Gaussian Liouvillian dressing
itself.

The resulting spectra and pointwise discrepancies are shown in
Fig.~\ref{fig:external_validation}.

\subsection{Internal Consistency of Spectral Evaluation}
\label{sec:validation_internal}

We next verify that the Cartesian-grid and arbitrary-coordinate
interfaces evaluate the same underlying response.
A finite-pulse Model-A spectrum was first calculated on a Cartesian
frequency grid using \texttt{finite\_pulse\_spectrum}.
The same spectral coordinates were then supplied as paired points to
\texttt{finite\_pulse\_points}, and the resulting values were reshaped
to the original grid.

The relative discrepancy was evaluated as
%
\begin{equation}
\epsilon_{\mathrm{grid/pts}}
=
\frac{
\left\|
S_{\mathrm{points}}-S_{\mathrm{grid}}
\right\|_F
}{
\left\|
S_{\mathrm{grid}}
\right\|_F
}.
\label{eq:grid_points_error}
\end{equation}
%
For the benchmark calculation,
%
\begin{equation}
\epsilon_{\mathrm{grid/pts}}
=
1.14\times10^{-16},
\end{equation}
%
showing agreement at numerical precision.
This test confirms that arbitrary-coordinate evaluation changes only
the set of requested spectral coordinates and not the underlying
finite-pulse response calculation.

The implementation additionally reuses frequency-dependent
Liouville-space objects whenever repeated values of $\omega_1$ or
$\omega_3$ occur in the requested coordinate set.
This makes the paired-coordinate interface suitable for sparse,
structured, and locally refined sampling patterns without introducing
a separate spectroscopic approximation.

\subsection{Targeted Frequency Sampling}
\label{sec:validation_sampling}

The arbitrary-coordinate interface also permits the spectral sampling
pattern to be adapted to the region in which the response carries
significant weight.
To demonstrate this capability, we use the same coupled-dimer model
analyzed in Sec.~\ref{sec:regime_study} and consider the full
finite-pulse nonrephasing response (Model A) at
$J=40~\mathrm{meV}$, $T=100~\mathrm{fs}$, and a pulse intensity
FWHM of $20~\mathrm{fs}$.

A dense reference spectrum was first evaluated on a
$641\times641$ Cartesian grid spanning
$1.75$--$2.25~\mathrm{eV}$ along both frequency axes.
A coarse $21\times21$ survey was then used to identify the region
containing the dominant spectral weight.
Using a threshold of $10\%$ of the maximum response magnitude,
followed by a one-cell padding of the selected region, gives the target
window
%
\begin{equation}
1.925 \le E_1 \le 2.075~\mathrm{eV},
\qquad
1.925 \le E_3 \le 2.100~\mathrm{eV},
\label{eq:sampling_target_window}
\end{equation}
%
where $E_j=\hbar\omega_j$.

We compare three sampling strategies at approximately equal coordinate
budgets: a uniform global grid, a separable grid restricted to the
target region, and a structured pattern that combines coarse global
coverage with denser sampling in the target region.
In each case, the sampled values are interpolated back onto the dense
reference grid, and the reconstruction error is quantified from the
full complex spectrum as
%
\begin{equation}
\epsilon_{\mathrm{rec}}
=
\frac{
\left\|
S_{\mathrm{rec}}-S_{\mathrm{ref}}
\right\|_F
}{
\left\|
S_{\mathrm{ref}}
\right\|_F
}.
\label{eq:reconstruction_error}
\end{equation}
%
This quantity measures the error introduced by the sampling and
reconstruction procedure; it is distinct from the physical
approximation errors defined in Sec.~\ref{sec:theory}.

At a coordinate budget of approximately $3.7\times10^3$ points,
the uniform global sampling strategy gives a reconstruction error of
$21.3\%$.
Restricting the sampling density toward the identified spectral region
reduces the error to $6.21\%$ for the targeted separable grid and to
$3.24\%$ for the structured adaptive pattern.
Thus, for this benchmark, redistributing a fixed sampling budget toward
the spectrally active region substantially improves reconstruction of
the full complex response.
The corresponding spectra and sampling patterns are shown in
Fig.~\ref{fig:targeted_sampling}.

The advantage of redistributing the sampling coordinates persists over
a range of sampling budgets, as shown in
Fig.~\ref{fig:sampling_efficiency}.
For a reconstruction error of approximately $10\%$, the uniform global
grid requires $8649$ evaluated spectral coordinates and a median
wall-clock time of $13.87~\mathrm{ms}$.
The structured adaptive strategy reaches a comparable error
($9.10\%$) using $1392$ evaluated coordinates and
$7.79~\mathrm{ms}$, including the initial survey.
For this benchmark, this corresponds to a reduction of approximately
$6.2\times$ in the number of evaluated spectral coordinates and
$1.8\times$ in wall-clock time.
The targeted separable strategy gives intermediate performance,
showing that the gain arises progressively as the coordinate budget is
concentrated toward the spectrally active region.
These factors are specific to the present model and reconstruction
procedure and are not intended as universal performance bounds.
