\section{Installation}
\label{sec:installation}

PULSUS requires Python~3.10 or newer. Install the released package with:
\begin{lstlisting}[style=shell]
pip install pulsus-spec
\end{lstlisting}
Then import it in Python:
\begin{lstlisting}[style=python]
import pulsus
\end{lstlisting}
The package name is \texttt{pulsus-spec}; the Python import name is
\texttt{pulsus}. NumPy, SciPy, Matplotlib and QuTiP are installed as
dependencies. The first example works in a Python script or a notebook, without
cloning the GitHub repository.

This manual previews development version~0.3.0.dev0. The new
\texttt{plot\_linear\_spectrum} function and the plotters' optional
\texttt{savepath} and \texttt{dpi} arguments are not in PyPI release~0.2.0.
Until the next release, use the updated development checkout for those
features: run \texttt{pip install -e .} from its root directory.
The first two-dimensional example uses the existing released interface.
