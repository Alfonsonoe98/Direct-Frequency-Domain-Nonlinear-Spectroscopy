PULSUS 0.3.0 adds a public linear-spectrum plotter and optional figure export for both linear and two-dimensional spectra.

- Use `pulsus.plot_linear_spectrum(omega, spectrum, ...)` to display the real part, imaginary part, or magnitude of a complex linear response. Curves have no markers by default; normalization and Matplotlib styling are optional.
- Pass `savepath="spectrum.png"` or `savepath="spectrum.pdf"` to either plotting helper to export a figure. `dpi` controls raster resolution. Omitting `savepath` saves nothing.
- Both helpers return editable Matplotlib objects. Continue to use `plt.show()` and `fig.savefig(...)`, including after changing labels, styles, or adding curves. Existing two-dimensional plotting calls retain their behavior.
- The linear tutorial, API reference, and PDF user manual cover the new plotting interface. The shorter README links to detailed method and scientific validation notes.
- Package metadata now links directly to the repository, documentation, and issue tracker.

Scientific response calculations are unchanged. The complete test suite contains 108 passing tests, including 46 plotting cases; the documented examples were also checked against an installed wheel.

Install or upgrade with:

```bash
pip install --upgrade pulsus-spec
```
