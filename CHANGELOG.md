# Changelog

## 0.3.0

- Add `plot_linear_spectrum` for real, imaginary, and magnitude views of a complex linear response, with optional normalization and Matplotlib styling.
- Add optional `savepath` and `dpi` arguments to both plotting helpers. A PNG or PDF filename selects the export format; saving is off by default.
- Preserve editable figure, axes, and artist returns, so callers can customize, display, and save figures afterward.
- Update the linear tutorial, API reference, and user manual with the new plotting interface and plain curves without markers.
- Add repository, documentation, and issue links to package metadata.
